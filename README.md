# 福祉日報システム — 商談用デモ

福祉事業所（生活介護・就労継続支援B型など）の **日報・連絡帳をWeb化** する業務アプリの **デモ環境** です。

**▶ デモを開く: https://utaaiwork-ops.github.io/fukushi-nippo-demo/**

---

## このデモについて

- 利用者名・職員名・記録内容・事業所名は **すべて架空のサンプル** です。実在の個人・団体とは一切関係ありません。
- ログイン不要で開けます（デモ用に自動でログイン済みの状態にしてあります）。
- バックエンドを持たない静的なデモです。データは閲覧中の端末内のメモリだけで動き、**保存・送信・外部通信は一切行われません**（ページを再読み込みすると初期状態に戻ります）。

## 何ができるアプリか

| 画面 | 内容 |
| --- | --- |
| ホーム | その日の対応状況（日報・連絡帳の入力進捗）を一目で把握 |
| 日報入力 | 利用者ごとに 出欠・支援時間・活動・送迎・食事・バイタルを記録 |
| 連絡帳 | 事業所共有欄・ご家庭より・申し送りを記録。**AIによる文章整形**に対応 |
| 履歴 | 過去日の記録を閲覧・PDF出力 |
| PDF出力 | 連絡帳を半ページ／従来形式でPDF化（日本語フォント埋め込み） |
| マスタ管理 | 利用者・職員・アカウントの管理 |

## 特長

- スマホ・タブレットでも使える現場向けUI（PWA対応）
- 連絡帳の文章を **AIが整形**して清書を補助（デモでは擬似的に再現）
- 音声入力に対応（対応ブラウザ）
- 管理者印の一括反映など、現場運用に沿った機能

## 技術構成

- フロントエンド: React 18 + Vite + TypeScript + Tailwind CSS + shadcn/ui
- 本番構成のバックエンド: Firebase（Firestore / Authentication / Cloud Functions）
- 本デモ: 上記フロントエンドを静的書き出しし、Firebase 接続部をインメモリのモックへ置き換えてサンプルデータで動作させたもの

本番システムのソースコードは非公開リポジトリで管理しています。
